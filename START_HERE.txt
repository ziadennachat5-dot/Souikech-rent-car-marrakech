================================================================================
    📊 BASE DE DONNÉES
================================================================================

TABLES:
    categories
        id TEXT PRIMARY KEY
        label TEXT
        icon TEXT
        createdAt DATETIME
        updatedAt DATETIME

    cars
        id TEXT PRIMARY KEY
        name TEXT
        brand TEXT
        categoryId TEXT (FK)
        categoryLabel TEXT
        description TEXT
        features TEXT (JSON)
        idealFor TEXT
        comfort TEXT
        usage TEXT (JSON)
        image TEXT
        createdAt DATETIME
        updatedAt DATETIME

================================================================================
    ❌ PROBLÈMES?
================================================================================

ERREUR: "Port 3000 déjà utilisé"
    → Tuer le processus ou utiliser un autre port
    → Voir TROUBLESHOOTING.md

ERREUR: "Cannot GET /api/cars"
    → Backend n'est pas lancé
    → Lancez: npm run server
    → Voir TROUBLESHOOTING.md

ERREUR: "CORS error"
    → Backend n'a pas CORS activé
    → Vérifier server/index.ts
    → Voir TROUBLESHOOTING.md

ERREUR: "Cannot find module"
    → Dépendances manquantes
    → Lancez: npm install
    → Voir TROUBLESHOOTING.md

DONNÉES VIDES:
    → API indisponible? Normal, utilise les données statiques
    → Lancez le backend pour données dynamiques
    → Initialisez la BD via /api/init
